# ADR-REVIEW-006: 검토 질문, 제한된 문맥, 개인 처리 기록

> ID: `ADR-REVIEW-006` · 소유: `REVIEW` · 기준: `2026-09-27`

- 상태: `SUPERSEDED`
- 근거: 리뷰 품질·탐색·작업 복원 개선에 대한 사용자 구현 위임.
- 대체하는 ADR: [ADR-REVIEW-003](ADR-REVIEW-003-bounded-manual-code-review.md), [ADR-REVIEW-005](ADR-REVIEW-005-evidence-admission.md). 아래 유지 계약 외에 입력 범위와 결과 분류를 확장한다.
- 대체한 ADR: [ADR-REVIEW-007](ADR-REVIEW-007-bounded-context-ranking.md). 문맥 선택 계약을 확장하고 다른 계약은 유지한다.

## 배경

잠금 메서드·조회 인자의 유사성만으로 위험을 추정하는 결과와 긴 카드가 사용자의 판단 부담을 늘렸다. 로그인 후 작업 위치와 동기화 기록도 잃었다.

## 결정

SUPPORTED 발견 사항과 NEEDS_CONTEXT 검토 질문을 구분하여 모두 저장·평가한다. 질문은 결함 수에 합산하지 않는다. 줄 검증은 자연어 주장의 진실성을 증명하지 않는다. 잠금 메서드 중복이나 같은 인자만으로 경합·쿼리 오류를 추론하지 않는다.

변경 파일 최대 8개와 관련 파일 최대 2개를 고정 HEAD에서 읽고 전체 입력 24KiB 안에서 사용한다. 주변 줄과 보조 파일은 실행·호출 그래프 분석을 대체하지 않는다. 관련 파일 수집 누락을 표시하고 원문은 메모리에서만 취급한다. 근거 조회는 인증된 팀 멤버의 연결된 저장소에서만 가능하며 접근·연결 세대를 외부 요청 전후 검사한다. 원문은 결과 DB/로그에 저장하지 않는다.

review_feedback은 개인별 상태와 메모를 저장한다. run/user/issue_key 유일성, 논리 참조, 상태 CHECK, UTC 기록을 사용한다. 처리 상태는 확인 완료/수정 예정/의도된 동작/잘못된 지적 및 미처리다. 작성자 본인의 최근 피드백만 다음 리뷰의 비신뢰 참고 데이터로 제공하고 자동 억제하지 않는다. 제목·경로 기반 동일성 비교는 휴리스틱이며 이번 미검출을 해결로 판정하지 않는다.

PR 화면은 개요/정적 분석/AI 리뷰/활동으로 나눈다. 질문과 검토 범위, 관련 코드와 처리 상태를 구분한다. 개인 피드백이 팀의 공식 승인 또는 병합 승인을 뜻하지 않는다.

## 영향과 한계

기존 결과는 재작성하지 않고 호환 표시한다. 새 모델 호출·게시·자동 수정은 추가하지 않는다. 더 넓은 문맥도 토큰과 파일 한도를 준수하며 공급자 호출은 회차당 최대 한 번이다. 구조·권한·마이그레이션·반례 평가와 실제 화면을 검증한다. 실제 모델 품질은 별도 유료 평가로 관측한다.

## 유지되는 계약

003의 DeepSeek/LangChain, 정적 Finding 불변, 매 요청 OWNER 동의, 접수/전송/저장 시 권한·연결 세대 검사, 익명 파일 ID, 비밀·제외 경로 필터, 호출 1회·출력 2000token·모델 60초/전체90초·UTC 일5회·동시1개·자동 재시도 금지·generation 중복 방지·외부 호출 전 예약·lease 실패 종결을 유지한다. 원문 prompt/diff/소스/응답 비저장과 HTML 비실행도 유지한다.

005의 evidence_lines 1~8개·제공 HEAD 줄·대표 줄과 변경 줄 포함, trigger/consequence 각1~400자, assumptions 최대3개 각400자, SUPPORTED의 빈 가정, NEEDS_CONTEXT의 비어 있지 않은 가정과 ERROR 금지를 유지한다. 구조 오류는 전체 응답 실패다. 분류 이동은 명시적으로 기록하며 지적을 평가 전에 제거하지 않는다.

프롬프트만 수정하면 읽기 부담과 작업 유실을 해결할 수 없다. 전체 저장소 전송/자동 LLM 재판정은 범위·비용 증가로 제외했다. 이름 매칭으로 선택한 최대2개 보조 파일은 호출 그래프가 아니며 누락 가능성을 표시한다. 006은 구현 완료를 증명하지 않으며 실행 보고서가 검증 상태를 소유한다.

## 대안

전체 저장소 전송과 자동 LLM 재판정 대신 고정 SHA·제한된 주변 코드와 보조 파일을 선택한다. 피드백은 자동 억제 규칙이 아닌 개인 참고 데이터로 유지한다.
