# ADR-REVIEW-007: 제한 문맥 검색과 선택적 로컬 재정렬

> ID: `ADR-REVIEW-007` · 소유: `REVIEW` · 기준: `2026-09-27`

- 상태: `SUPERSEDED`
- 근거: 문맥 수집 개선·동일 후보 리랭커 비교·효과 확인 후 도입의 세 단계를 사용자가 위임했다.
- 대체하는 ADR: [ADR-REVIEW-006](ADR-REVIEW-006-review-workflow.md). 문맥 선택과 검색 예산만 대체하며 나머지 계약은 아래와 같이 유지한다.
- 대체한 ADR: [ADR-REVIEW-008](ADR-REVIEW-008-team-daily-allowance.md). 일일 한도만 변경하며 문맥 선택 등 나머지 계약은 유지한다.

## 배경

이름순 두 파일의 첫80줄은 관련 메서드·직접 참조를 놓칠 수 있다. 고정 HEAD에서 import/식별자/경로 관계로 후보 파일을 최대12개 읽고 최대24개 함수·메서드 구간을 만든다. 구간은 최대80줄이며 최종 관련 파일은2개, 변경 파일8개/전체 JSON24KiB를 유지한다. 전체 호출 그래프나 저장소 전체 인덱스를 만들지 않는다. 같은 이름의 다른 선언/동적 호출은 남는 한계다.

## 결정

기본 선택은 결정적 규칙이다. 선택적 로컬 리랭커는 동일 후보의 관련성을 점수화하며 변경 코드를 제거하지 않는다. CPU 컨테이너와 호스트 loopback으로 격리하고 외부 리랭커 사업자에 코드를 보내지 않는다. 공식 모델 revision/파일 해시를 고정하며 요청 중 다운로드·원격 Python 코드·사용자 코드 실행을 금지한다. 입력·동시성·CPU·메모리·시간을 제한하고 오류·timeout·비정상 점수는 규칙 선택으로 복귀하며 metadata에 사유를 남긴다.

BOUNDED_CODE_V3 결과에 선택 방식/후보 수/누락 사유/사용한 모델 버전을 기록한다. 질의·후보 원문은 메모리에서만 처리한다. 기본 OFF에서 동일 corpus 비교를 수행하고 최종 근거 포함률·오탐/질문·결함 누락·지연/비용이 사전 기준을 충족할 때만 활성화한다. 실험 모델의 검색 학습 성능을 코드 검토 정확도로 주장하지 않는다. 비교 결과와 도입 상태는 구현 Report가 소유한다.

## 유지 계약

006의 개인 피드백/질문 분리/고정 소스 조회/과거 결과 불변 계약을 유지한다. DeepSeek/LangChain, 매 요청 OWNER 동의, 권한/연결 세대/lease 검증, 익명 ID, 비밀/제외 경로 필터, 근거 HEAD·변경 줄·가정 검증, 원문 DB/로그 비저장, 도구 미제공, 한 회차 DeepSeek1호출·출력2000토큰·60초/전체90초·일5회·자동 재시도0을 유지한다. 로컬 재정렬은 별도 유료 LLM 호출이 아니다. 실패 복귀가 문맥 완전성을 보장하지 않으므로 누락을 표시한다.

## 영향과 한계

관련 소스 취득과 CPU 추론의 시간·메모리가 추가된다. 모델 점수는 사실성이나 호출 관계의 증명이 아니며, 후보 밖의 코드와 잘린 입력은 복구하지 못한다. 실제 모델·하드웨어·코드 corpus에 따라 이득이 없거나 악화될 수 있다. 측정 없이 기본 활성화하지 않는다.

## 대안

전 저장소 벡터 인덱스/영속 RAG, 외부 재정렬 API, 고비용 모델의 즉시 기본 활성화는 도입하지 않는다. 규칙만 개선하는 결과도 유효한 채택 결정이다. 같은 후보/예산/정답에서 실제 모델을 비교하고 악화 사례를 숨기지 않는다. 안전한 소스 취득·줄 경계·언어 지원·큰 파일·예산·비밀·접근 철회·리랭커 중단/시간초과/형식 오류·Job 처리 회귀를 검증한다.
