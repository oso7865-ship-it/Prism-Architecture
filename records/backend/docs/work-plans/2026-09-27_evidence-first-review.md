- 목표: 순위 때문에 직접 호출 근거가 사라지는 문제, 같은 파일의 다른 함수 누락, PR 전체 질의 편향, 정상 코드 지적/잘못된 부연, 줄 번호만 맞으면 통과하는 평가를 개선한다.
