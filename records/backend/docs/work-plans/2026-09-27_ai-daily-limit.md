# 팀 AI 리뷰 한도 30회·모델 표시 정비

- 요청: 팀당 하루 한도를 30회로 올리고 화면의 DeepSeek 이름을 AI 모델로 변경한다.
- 범위: M. backend/frontend dev, architecture main. 기존 미커밋 변경 보존. 기본 한도와 설정 최대값 30, 최소값1 유지. 로컬 .env와 개발/운영 예시도 30으로 맞춘다.
- 정책: UTC 접수일 기준(한국시간 오전9시 초기화), 팀 단위 합산, 실패·취소 포함, 동시1개, 소유자 동의, 자동재시도0 유지. 기존 기록 재조회는 차감 없음. 새 유료 호출 없음.
- UI: API daily_limit 응답 사용 유지. 초기값도30으로 맞춘다. 동의/설명/헤더/연결 실패와 사용내역 안내는 AI 모델/AI 서비스로 표현하되 전송 데이터와 비용 안내를 유지한다. 실제 제공자·모델 설정과 운영 문서는 보존한다.
- 설계 기록: ADR-REVIEW-008로 기존007의 일일5회만 대체. 소유 문서·결정 맵·context-map 동기화. 과거 보고서·기존 ADR 결정 본문은 소급 수정하지 않는다.
- 위험 판정: 한도 상향과 비파괴적 로컬 설정 변경은 이번 사용자 지시로 승인됨. 권한·데이터 스키마·과금 처리 변경 없음. 재시작 전 활성 Job/리뷰 확인. 자동 추가 결제/유료 평가 없음.
- 검증: 설정1~30 범위, 서비스30번째 허용/31번째 차단(대역·Linux 임시 DB), 기존 리뷰 회귀, 프론트 렌더·타입·빌드, 문서 무결성, API 재시작 후 실제 UI30회 및 AI 모델 문구. Windows DB 테스트 제외.
- 적용: verification-loop, terminal-ops. 화면 문구는 직전 사용자 언어 정책 유지.
