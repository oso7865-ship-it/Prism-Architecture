# 전체 화면 레이아웃 정렬

- 요청: 계정 메뉴처럼 어긋난 배치를 전체 화면에서 찾아 읽고 조작하기 편하게 정리한다.
- 범위: M, Vue polish. frontend dev의 공통 표시 컴포넌트·CSS·마크업. 기존 변경을 보존한다.
- 적용: ui-ux-design, vue-ui-polish(polish), browser-qa, verification-loop, terminal-ops. Product Design audit로 현재 화면을 먼저 캡처한다.
- 관측: 320px 코드 점검 제목의 아이콘이 홀로 줄바꿈되고 4열 탭에서 'AI 리뷰'가 쪼개진다. 홈 목록 상태·화살표와 멤버 배지가 고정 margin 들여쓰기로 이름 아래 어긋난다. 초대 폼은 2개 요소에 3열을 할당하고, PR 상세의 가용 폭과 무관하게 숫자 요약이 3열을 유지한다.
- 증거: workspace audit-artifacts/2026-09-27-layout-alignment/01~05 before 캡처. 이후 AI 카드·로그인도 캡처해 확인한다.
- 설계: 제목/아이콘/보조 정보와 펼침 행을 공통 컴포넌트로 묶는다. 목록은 아이콘·본문·상태의 명시적 grid를 사용한다. 작은 카드에서는 상태를 본문 아래, 화살표를 우측에 둔다. 상세 영역의 실제 폭에 따라 탭은 2열, 요약은 라벨/값 행으로 전환한다. 입력과 실행 버튼은 같은 바닥선·44px 이상, 모바일에서는 한 열로 배치한다.
- 유지: 파란색 토큰, 정보/상태/원문, 네이티브 details와 키보드 조작, API·라우트·AI 정책. 별도 의존성·유료 호출 없이 기존 데이터로 확인한다.
- 검증: 기존 회귀·타입·빌드, 실제 로그인/홈/저장소/팀/개요/점검/AI/기록 화면 점검. 대표 화면 320/375/414/768/1280px 넘침과 요소 위치 측정, 필터/탭/펼침/계정 메뉴 키보드 동작. 초대 생성·역할 변경·리뷰 요청 등 데이터 변경은 필요 없음.
