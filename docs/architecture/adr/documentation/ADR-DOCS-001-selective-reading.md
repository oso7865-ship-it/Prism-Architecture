## 배경

사용자의 명시적 선택 또는 기존 결정 기록을 이관한다. 아래 대안은 기존 기록과의 대비이며 실제 벤치마크나 당시의 상세 논의를 재구성한 것이 아니다.

## 결정

공통 기준 이후 작업에 필요한 소유 문서만 읽는다. context-map.json으로 작업과 경로를 매핑한다.

## 대안

거대 통합 문서를 기본 컨텍스트로 제공하는 방식은 선택하지 않는다.

## 영향과 한계

문서 추가 시 ID·상대 링크·읽기 매핑을 함께 유지한다.
