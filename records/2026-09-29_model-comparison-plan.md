# Flash / Pro 재측정 계획

상태: 479회 실행·312평가 완료, Pro 일괄 교체 보류. [결과 보고서](2026-09-29_model-comparison-report.md). 규모 L. 사용자 요청: Flash 대신 한 단계 높은 DeepSeek 모델로 품질 재측정. 시작 시 이전 품질 캠페인 5,000회 승인 중 1,431회 사용, 3,569회 남음. 이번 비교는 최대480회, 자동 재시도0, 동시 요청4개다. 기존 캠페인 원장에서 호출 전에 예약한다. 인증/결제 오류 또는 연속12개 오류에는 중단한다.

## 작업 계약

- 대상: backend dev의 평가 코드/테스트, architecture main의 계획·원장·결과. 기존 제품 변경은 보존한다. 제품 모델/프롬프트/DB/프론트/배포/Git 게시 변경은 포함하지 않는다.
- 근거: [1차 실험](2026-09-29_quality-lab-report.md), CORE와 review 문서, backend AGENTS/Quick Ref/GateGuard. Verification Loop·Terminal Ops 규칙 적용. 유료 외부 호출 위험은 사용자의 기존 최대5,000회 승인과 이번 모델 변경 요청으로 충족한다. 새 자료는 기존 합성 코드와 공개 최소 재현만 전송한다.
- 모델: `deepseek-flash`와 `deepseek-v4-pro`. [현재 가격표](https://api-docs.deepseek.com/quick_start/pricing/)는 각각 V4.1-Flash, V4-Pro-0813으로 설명한다. [변경 이력](https://api-docs.deepseek.com/updates/)의 Pro 유지 공지와 실제 `/models` 결과도 보존한다. 과거 종료 공지와 혼동하지 않는다. 응답의 모델 이름은 제공자가 반환한 식별자이며 내부 가중치의 독립 검증은 아니다.
- 보호: API 키·추론 전문·원시 예외 응답은 기록하지 않는다. 모델이 생성한 코드와 분석 대상 문자열은 실행하지 않는다. 사람이 사전 작성한 기준 동작만 검증한다. Windows 접근 위반 재발을 피하기 위해 테스트는 Linux 컨테이너에서 실행한다.

## 공정 비교

1. 이전에 고정한36사례를 동일한 진단 스키마로 두 모델×2회:144호출. 구체 입력의 반환/예외 예측과 결함 위치/정상 오탐을 분리한다.
2. 제품의 초안→근거 검증 또는 빈 답변 재검토 경로:36사례+기존 공개6사례, 두 모델×2회×최대2호출=336호출. 이전 프로토콜을 그대로 사용한다. 후속 단계 입력은 초안에 의존하므로 서로 달라질 수 있다.
3. 비추론 모드, temperature0, 출력2,000토큰, 요청 제한60초를 같게 유지한다. 입력/시스템 해시를 비교한다. 순서를 섞되 각 조건을 번갈아 실행하고 같은 시기에 Flash 대조군을 새로 측정한다. 사전 smoke 요청은 본 실험의 첫 결과로 재사용한다.
4. 기존 holdout은 이미 관측했으므로 이번에는 모두 회귀 사례다. 미사용 검증셋/통계적 우월성/전체 실서비스 성능을 주장하지 않는다. Java/Python 표준 예외명의 허용된 별칭은 두 모델에 똑같이 적용하고 strict 점수도 남긴다.

## 판정 및 기록

- 형식 실패, 파이프라인 미완료, 누락, 정상 오탐, 불필요 질문, 구체 동작 정답, p50/p95 시간, 입력/출력·캐시 토큰, 제공자 응답 모델 이름을 기록한다. 실패 호출도 사용량에 포함한다. 단가 기반 비용은 청구서가 아닌 추정 범위다.
- `range`/인증서 환경 변수/중첩 복사/정수 오버플로 등 기존 의미 오류를 초안과 최종 답에서 수동 검수한다. 위치 적중만으로 원인/수정안까지 정답으로 간주하지 않는다. 수정안이 정상 입력 계약을 유지하는지도 확인한다.
- 자동 채택 기준: 누락·오탐·형식 실패 증가0, 기존 중요한 해석/수정안 오류 개선, 지연·비용 증가의 실익. 이 비교만으로 제품을 자동 변경하지 않고 근거와 추천을 보고한다.
- 완료: 재개·호출 상한·모델 분리·입력 동일성 오프라인 검사, 실제 API 측정, 의미 검수, 잔여 예산과 WORKING_CONTEXT/LATEST 갱신, 문서 검사. 이전1,431회 결과는 변경하지 않는다.
