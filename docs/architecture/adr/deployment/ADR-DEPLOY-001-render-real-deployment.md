## 배경

사용자의 명시적 선택 또는 기존 결정 기록을 이관한다. 아래 대안은 기존 기록과의 대비이며 실제 벤치마크나 당시의 상세 논의를 재구성한 것이 아니다.

## 결정

백엔드 Render와 저비용 MVP 방향을 유지하며 실제 주소로 배포할 계획이다.

## 대안

다른 호스팅으로의 전환은 아직 결정하지 않았다.

## 영향과 한계

도메인·Callback·DB 호스팅은 미정이다. 실제 배포 완료를 뜻하지 않으며 무료 환경 제약은 배포 소유 문서를 따른다.
