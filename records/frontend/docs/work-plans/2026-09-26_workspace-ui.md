# 작업 공간 UI/UX 재설계

## 작업 계약
- 목표: 로그인한 팀원이 저장소를 선택하고 PR 목록·상세를 바로 탐색한다.
- 모드: redesign. 기존 Vue/CSS·인디고 브랜드·API·권한·파괴적 동작 확인을 보존한다.
- 범위: HomeView, WorkspacePanel, 공통 아이콘/상태와 PR 상세 컴포넌트, CSS 토큰, UI 상태·사용자 문구. backend/아키텍처/하네스 사본 동기화/게시 제외.
- 근거: 사용자 UIUX/위치/안정감 개선 요청. dev에서 작업. 기존 미커밋 변경 보존.
- 스킬: ui-ux-design, vue-ui-polish, browser-qa, verification-loop. Gate: UI/UX, API, Security, Document.

## 설계
기존 문제는 동일한 카드 안에 팀 생성·초대·멤버·저장소·PR을 모두 노출해 핵심 과업이 아래로 밀리는 것이다. 계정은 상단, 팀 선택/탐색은 좌측, 저장소와 PR은 본문에 배치한다. 사용자 추가 요청에 따라 /login → /app → /app/repositories 또는 /app/team으로 실제 Vue Router 페이지를 분리한다. 비로그인 접근은 /login으로 이동하고 새로고침 시 세션을 복구한다. 팀 설정은 별도 페이지로 전환하고 생성/수락/연결 폼은 disclosure로 연다. 로그인 전에는 설명과 로그인 행동만 중심에 둔다. 개발 연결 확인은 보조 disclosure로 내린다.

모바일은 상단 팀 선택/가로 탐색→저장소→PR목록→상세 단일 열. PC는 232px 탐색 레일+유연한 본문, 충분히 넓을 때 PR목록/상세를 분할한다. 최소320px. 본문 최대1360px, 반복 간격8/12/16/24/32px, 버튼 최소44px. 기본타입14~16px, 과업 제목28px. 회색 배경/흰 표면/얇은 경계/인디고 주요행동, 상태는 색상+한국어. 과장된 그림자/그라데이션/등장 모션 없음. DESIGN_VARIANCE=3/10, MOTION_INTENSITY=1/10, VISUAL_DENSITY=5/10.

로딩 중 조작 차단과 진행 안내, API 오류는 재시도, 미연결/빈PR/필터0건/리뷰0건을 구분한다. UNKNOWN은 '병합 여부 미확인', Draft는 '초안'으로 표시한다. PR 결과와 리뷰 원문을 혼동하지 않게 한다. 현재 API를 그대로 사용하며 가짜 통계·미구현 분석 버튼을 만들지 않는다.

native 버튼·select·details, label/focus-visible/aria-live, 닫기/취소와 기존 confirm을 유지한다. 상세 진입 시 제목으로 포커스 이동, 닫기 시 목록 버튼으로 복귀. 검색은 가져온 목록에만 적용된다. 위험 동작은 팀 설정 또는 저장소 관리 disclosure로 분리한다.
