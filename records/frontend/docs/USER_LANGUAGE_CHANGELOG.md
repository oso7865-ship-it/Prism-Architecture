# 사용자 친화적 문구 변경 이력

작성일: 2026-09-27 · 적용: frontend dev working tree

## 표시 원칙·검증

- 내부 enum, API 주소, URL의 `tab=static`, 데이터 필드와 권한 로직은 그대로 사용한다. 사용자에게 보이는 이름을 변경했다.
- 사용자 작성 제목, 저장소/파일명, 코드·변수·커밋 해시, 기존 AI 답변 원문은 임의로 번역하지 않는다. 필요한 기술 정보는 설명과 함께 제공한다.
- 코드 점검은 실행 테스트가 아니다. AI 제안은 검증 완료된 결함이 아니다. 코드 반영은 배포 완료를 뜻하지 않는다.
- 실패·취소 비용과 전송 범위, 코드 수집 한도는 유지한다. 한국시간 오전 9시는 UTC 자정과 같은 시각이다.
- 알 수 없는 내부 값은 이전 작업의 한국어 fallback을 계속 사용한다.
- 108개 테스트, 타입 검사·빌드, 실제 화면 검수의 상세 결과와 제한은 [작업 보고서](../reports/2026-09-27_plain-language_report.md)를 따른다.
