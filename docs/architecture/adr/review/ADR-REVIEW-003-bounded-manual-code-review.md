# ADR-REVIEW-003: 제한된 코드 문맥의 수동 AI 리뷰

> ID: `ADR-REVIEW-003` · 소유: `REVIEW` · 기준: `2026-09-26`
> 읽는 때: AI 코드 전송·접수·예산·응답 계약을 구현할 때

- 상태: `ACCEPTED`
- 기록일: `2026-09-26`
- 근거: 사용자가 설계 후 1~6 단계 전체 구현과 PR 실제 검증을 승인함.
- 대체하는 ADR: [ADR-REVIEW-001](ADR-REVIEW-001-optional-explanations.md)
- 대체한 ADR: 없음

## 배경

사용자가 실제 DeepSeek 코드 리뷰를 요청했다. 기존 FINDINGS_ONLY 설계는 코드 문맥을 검토할 수 없어 제한적인 소스 전송 계약이 필요하다.

## 결정

정적 Finding과 AI는 분리하고 DeepSeek/LangChain을 유지한다. FINDINGS_ONLY 초기 기본값을 BOUNDED_CODE_V1으로 확장한다. 초기에는 OWNER만 매 요청에 코드 외부 전송을 동의하고 수동 실행한다. 자동 AI·GitHub 게시·코드 실행/적용은 없다.

최대 8개 파일의 HEAD 변경 및 주변 줄, patch당 8KiB, 전체 JSON 입력 24KiB와 최대 10개 비밀 제외 정적 Finding을 전송한다. 파일 경로는 익명 ID로 대체하고 제외 경로·비밀 의심 파일을 차단한다. 비밀 탐지는 완전하지 않으며 사용자가 코드 반출 적합성을 판단해야 한다.

요약/발견/근거/제안/한계를 strict schema와 실제 전송한 파일/줄로 검증한다. 도구·쓰기 권한과 외부 tracing은 주지 않는다. 초기 review_runs JSON 결과는 별도 FindingExplanation 테이블을 대신한다. 원문 diff/prompt/모델 응답은 DB·로그에 저장하지 않는다.

한 실행 1회 호출·출력 2000 token·60초, Workspace UTC 일 5회·동시 1개. 자동 재시도 없음. 중복은 기존 실행 재사용, 명시 재실행은 별도 generation. 호출 시도는 외부 요청 전에 저장하고 lease 만료 시 불확정 과금 실패로 종결한다. 돈 단위의 정확한 과금은 Provider 청구가 기준이다.

## 대안

정적 규칙 설명만 제공하면 코드 문맥을 리뷰할 수 없다. 전체 저장소 전송은 초기 범위에 비해 과도하다. 제한된 HEAD 문맥은 삭제 코드·파일 밖 의존성을 판단할 수 없으며 결과에 이를 명시한다. 요청·전송 전·저장 시 현재 권한/연결 세대를 확인한다. 취소가 이미 전송된 요청의 과금을 되돌리지는 않는다.

## 영향과 한계

파일 밖 동작·실행 결과를 검증하지 않으며 비밀 탐지는 불완전하다. 횟수/출력 제한은 금액 상한 보장이 아니다. 사용자가 코드 전송에 동의하며 모델 결과를 검토해야 한다.
