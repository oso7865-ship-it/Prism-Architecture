# ADR-REVIEW-008: 팀별 AI 리뷰 하루 30회

> ID: `ADR-REVIEW-008` · 소유: `REVIEW` · 기준: `2026-09-27`

- 상태: `SUPERSEDED`
- 근거: 사용자 명시 결정 — 팀별 하루30회. 사용자 화면은 제공자 고유명 대신 AI 모델로 표시한다.
- 대체하는 ADR: [ADR-REVIEW-007](ADR-REVIEW-007-bounded-context-ranking.md). 일일 접수 한도만 대체하며 문맥 검색·재정렬·결과·보안 계약은 유지한다.
- 대체한 ADR: [ADR-REVIEW-009](ADR-REVIEW-009-derived-review-summary.md). 사용자 요약 구성만 변경하며 일일 한도 등 나머지 계약은 유지한다.

## 배경

기존 팀별5회는 현재 개발·검토 사용량에 부족하다는 사용자 결정에 따라 한도를 조정한다.

## 결정

팀 기준의 기본값과 설정 최대값을5회에서30회로 올린다. 설정 범위는1~30회로 필요시 낮출 수 있다. 모든 저장소·요청자를 팀으로 합산하며 계정 전체의 별도 한도는 추가하지 않는다. UTC 접수일 기준으로 계산하고 한국시간 오전9시에 초기화된다. 실패·취소된 접수도 소비하며 중복 요청의 기존 실행 재사용과 과거 조회는 추가 차감하지 않는다. 30번째 신규 접수까지 허용하고31번째는 AI_DAILY_LIMIT으로 거절한다.

동의·설명·상태 안내와 모델 배지는 특정 제공자 이름 대신 AI 모델/AI 서비스로 표현한다. 변경 코드·관련 코드·개인 검토 메모·점검 요약의 외부 전송과 비용 가능성은 계속 명시한다. 실제 제공자는 DeepSeek이며 서버 설정·운영 기록의 모델 정보는 보존한다.

## 유지 계약

007의 BOUNDED_CODE_V3, 변경8파일·관련2파일·입력24KiB, 후보12파일·24구간·구간80줄, 결정적 규칙 우선·로컬 리랭커 기본OFF·오류시 규칙 복귀를 유지한다. 이전006/005의 개인 기록·질문 분리·고정 소스·근거 HEAD/변경 줄/가정 검증·과거 결과 불변도 유지한다. DeepSeek/LangChain, 매 요청 OWNER 동의, 팀당 동시1개, 호출1회·자동재시도0, 출력2000토큰·모델60초/전체90초, 권한·연결 세대·lease 검증, 비밀 필터·도구 미제공·대상 코드 비실행·원문 DB/로그 비저장을 유지한다.

## 대안

5회 유지는 사용자 요구를 충족하지 못한다. 무제한·계정별 새 제한은 이번 요청에 포함하지 않는다.

## 영향과 한계

허용 접수량은6배가 되지만 금액 상한을 보장하지 않는다. 공개 운영 금액 예산/알림은 기존 미정 항목이다. DB 변경이나 기존 사용량 초기화 없이 새 한도를 적용한다. 환경값을 낮추고 API를 재시작하면 되돌릴 수 있다.
