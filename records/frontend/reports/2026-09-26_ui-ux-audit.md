# PRism UI/UX 자체 검수

> 작업 브랜치: dev (과거 작업 시점; 원래 본문 범위 참조)
> 커밋/PR: 작성 당시 미커밋; 현재 게시 상태는 reports/_LATEST.md 참조
> 작업 범위: M
> 형식 상태: legacy
> 과거 적용 스킬 기록: 미확인 (이전 본문에 남은 적용 기록만 유효)
> 적용 Gate: 기존 본문 검증 범위 참조; 새 Gate 수행을 소급 주장하지 않음
> 위험도: 일반 (기록 형식 정정; 과거 작업 위험은 본문 참조)
> 형식 정정: 2026-09-26 게시 준비 중 누락 헤더 정리. 과거 검증을 재실행한 것으로 간주하지 않음.

2026-09-26. 목적: 로그인, 홈, 저장소/PR, 분석 결과, 팀 설정의 작업 동선 검수. 제품 코드 수정 없이 현재 화면과 실제 탐색/새로고침으로 확인. CUA mcp__cua_repl 사용. Chrome 기존 로그인 세션과 IAB 로그인 화면. 모바일 viewport 375×812, 문서 clientWidth/scrollWidth 모두 360px. 임시 viewport 복원 완료.

## 단계별 평가

1. 로그인: 양호. 단일 GitHub CTA와 저장소 선택 시점, AI 준비 상태가 명확함. 인증 자체는 재실행하지 않음. 증거 07-login.png.
2. 홈: 개선 필요. 저장소 바로가기는 정상이나 소개 문구와 개수 요약이 PR 이어보기보다 위를 차지함. 증거 02-home.png.
3. 저장소/PR: 우선 개선. PR #47을 연 뒤 새로고침하면 상세가 사라지고 목록으로 돌아감. URL에 team만 있고 선택 PR이 없음. 모바일 PR 목록 제목 y=971px. 증거 03-analysis.png, 04-after-reload.png, 05-mobile-repositories.png.
4. 분석 결과: 우선 개선. 발견 항목에 파일/줄은 표시되나 링크가 없고 GitHub PR 전체 링크만 있음. 분석 완료 상태에서도 현재 PR 분석과 같은 커밋 재분석이 분리되어 표시됨. 증거 06-mobile-detail.png 및 DOM.
5. 팀 설정: 개선 필요. 숫자 GitHub ID를 상대방 계정 메뉴에서 알아내야 초대할 수 있음. 증거 01-team.png.

## 우선순위와 제안

- P1 작업 위치 복원: 저장소/PR/분석 이력을 URL에 반영하고 새로고침/뒤로가기/공유 시 복원. 재현은 PR 상세 소실까지 확인했으며 뒤로가기는 별도 검증 필요.
- P1 코드로 이동: 발견 항목의 파일·줄을 분석 대상 commit SHA에 고정한 GitHub 링크로 제공. 가능하면 코드 문맥 미리보기.
- P1 모바일 정보 구조: 팀 생성·참여·새로고침은 접힌 메뉴에, 저장소는 간결한 선택기로. PR 상세 진입 시 저장소 목록을 축소하고 목록 복귀와 PR 제목 우선 표시.
- P2 분석 CTA 정리: 미분석/진행/완료 상태별 대표 행동 하나. 완료 시 재분석을 대표 행동으로, 결과 새로고침은 보조로. 이번 검수에서 분석 POST는 실행하지 않았으며 두 버튼의 동작 차이는 검증하지 않음.
- P2 팀 초대 입력: GitHub 사용자명 검색 → 계정 미리보기 → 초대. 숫자 ID 조회 부담 제거. 권한·초대 보안 계약은 별도 설계.
- P2 홈 우선순위: 최근 PR/분석과 이어할 작업을 상단으로, 서비스 소개는 하단으로. 현재 홈의 안내 영역이 반복 사용자에게 과도한 비중을 차지한다는 디자인 판단.

## 접근성 및 한계

상태가 텍스트로도 표시되고 폼에 레이블이 있으며 본문 이동 링크와 상세 제목 포커스를 DOM에서 확인. 모바일 해당 화면 가로 넘침 없음. 작은 보조 텍스트는 확대 검수 권장. 스크린리더, 키보드 전체 순회, 색 대비 비율, 200% 확대, 실패/권한 없음 상태는 이번에 검증하지 않아 접근성 준수를 판정하지 않음.

캡처는 assets/2026-09-26-ui-audit/에 저장. 06은 full-page 캡처 특성상 고정 헤더가 중간에 보이므로 헤더 겹침 결함 근거로 사용하지 않음. 이전 디자인 보고서의 테스트 결과를 이번 검수 증거로 재사용하지 않음.
