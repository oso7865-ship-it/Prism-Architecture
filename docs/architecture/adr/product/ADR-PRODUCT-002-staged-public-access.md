## 배경

사용자의 명시적 선택 또는 기존 결정 기록을 이관한다. 아래 대안은 기존 기록과의 대비이며 실제 벤치마크나 당시의 상세 논의를 재구성한 것이 아니다.

## 결정

다른 사용자도 가입·저장소 연결할 수 있는 구조로 개발한다. 초기에는 본인 GitHub Organization과 개인 프로젝트에서 사용하며 즉시 공개 출시하지 않는다.

## 대안

즉시 외부 공개 출시하는 방향은 채택하지 않았다.

## 영향과 한계

공개 시점·상용화·코드 처리 계약·삭제 운영은 외부 사용자를 받기 전 결정한다.
