## 배경

기존 문서의 설계 기본값을 이관하며 사용자 개별 승인·실행 검증으로 간주하지 않는다. 아래 대안은 기존 기록과의 대비이며 실제 벤치마크나 당시의 상세 논의를 재구성한 것이 아니다.

## 결정

Vue/Vercel과 동일 출처 API 프록시를 기존 설계 기본값으로 유지한다. Vue 3·TypeScript·Vite·Vue Router 세부 조합은 제안 상태다.

## 대안

다른 프론트 스택과의 비교·최종 버전 고정은 수행하지 않았다.

## 영향과 한계
