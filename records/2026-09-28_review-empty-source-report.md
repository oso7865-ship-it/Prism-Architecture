# 빈 리뷰 재검토·사이트 내 코드 보기

> 날짜: 2026-09-28 · backend/frontend dev, architecture main · 커밋/푸시/배포 미수행

## 원인과 범위

사용자가 지적한 화면은 제안·질문이 모두0건인 완료 결과였다. 최신4개 DB 기록은 call_attempts=1, verification=NO_CANDIDATES, 유지/수정/제외 모두0이었다. 모델의 첫 빈 답변을 재검토 없이 완료하는 경로였다. UI 누락이나 verifier가 지적을 삭제한 증거는 없으며, 과거 지적이 있었다는 이유만으로 실제 결함 누락을 확정하지 않는다.

[작업 설계](2026-09-28_review-empty-source-plan.md), [ADR-REVIEW-011](../docs/architecture/adr/review/ADR-REVIEW-011-empty-recheck-and-source-view.md). UI/UX Design·Vue UI Polish·Verification Loop 및 Security Gate 적용. 기존 AWS 문서 변경과 과거 결과 보존, 문서는 아키텍처 저장소에만 기록.

Linux 타입 검증을 막던 기존 Windows 전용 CREATE_NO_WINDOW 상수 접근을 getattr 기본값으로 바꿨다. Windows 창 숨김 동작은 유지한다.

## 한계와 확인 방법

0건 자체가 오류는 아니다. 같은 모델이 반복해서 놓칠 수 있고 입력 범위 밖의 코드도 있다. 기존 의미 품질 미해결 항목을 해결했다고 주장하지 않는다. 기존 결과는 재작성하지 않으므로 현재 화면의0건은 남는다. 전송 동의 후 **AI 리뷰 다시 받기**로 새 결과를 만들면 파일별 재검토가 적용된다. **AI가 살펴본 범위 → 코드 보기**, 카드의 **사이트에서 코드 보기**, **근거 줄 코드 보기**로 이동 없이 코드를 확인한다.
